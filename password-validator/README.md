# Password Validator

A simple console-based password validator built with Python.

## Rules

A valid password must contain:
- At least 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit
- At least one special character

## How it works

The user enters a password, and the program checks it against all rules independently. Every unmet rule is reported at once, so the user sees the full list of what's missing rather than stopping at the first error.
