# To-Do List

A simple console-based to-do list application. Written to practice core Python list operations (add, remove, sort) and slicing through basic CRUD functionality.

## Features

- Add a task
- List tasks with numbering
- Mark a task as completed
- Delete a task
- Sort tasks alphabetically
- Show recently added tasks (slicing)

## Python Concepts Used

- Lists (`append`, `remove`, `sort`)
- Slicing (`list[-3:]`)
- `enumerate()`
- Error handling with `try/except`
- Functions

## Run

\`\`\`bash
python3 todo-list.py
\`\`\`

## Menu

1. Add Task
2. List Tasks
3. Complete Task
4. Delete Task
