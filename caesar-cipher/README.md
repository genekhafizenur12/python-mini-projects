# Caesar Cipher

A simple Python program that encrypts and decrypts text using the
Caesar Cipher method, with support for the Turkish alphabet.

## Features

- Encrypt and decrypt text with a custom shift value
- Supports Turkish characters (ç, ğ, ı, ö, ş, ü)
- Preserves spaces and punctuation
- Handles both uppercase and lowercase letters
- Simple menu-based interface

## Usage

```bash
python3 caesar-cipher.py
```

Follow the on-screen menu to encrypt or decrypt text.

## Example

```
Metin: merhaba
Kaydırma değeri: 3
Sonuç: phukded
```
