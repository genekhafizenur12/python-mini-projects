# 🎯 Number Guessing Game

A simple command-line number guessing game written in Python.

## Features

- Generates a random number between 1 and 100
- User chooses the number of attempts
- Score decreases after each wrong guess
- Higher/Lower hints
- Validates user input (1–100)

## Technologies

- Python

## How to Run

```bash
python number_guessing_game.py
```
