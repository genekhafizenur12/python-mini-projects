# Student Registration System

A simple file-based (txt) student registration system built with Python. It follows CRUD (Create, Read, Update, Delete) logic and runs through a console menu.

## Features

- **Add Student** — Creates a new student record with name, surname, and student ID.
- **List Students** — Prints all registered students to the screen.
- **Search** — Finds a student by their student ID.
- **Update** — Updates a student's name, surname, or ID (fields left blank stay unchanged).
- **Delete Student** — Removes a student record by student ID.
