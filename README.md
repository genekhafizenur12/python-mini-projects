# Projects

A simple game where the user tries to guess a randomly generated number.

A program that checks whether a given number is prime.

A simple calculator that performs basic mathematical operations such as addition, subtraction, multiplication, division, exponentiation and square root.

A calculator that uses Python's `*args` to accept a flexible number of operands, applying the chosen operation across all of them.

A terminal-based Rock-Paper-Scissors game against the computer, with score tracking and a target winning score.

A simple BMI calculator that takes weight and height, then returns the BMI value and category.

## 🎲 Dice Roll
A simple dice roll simulator.

## 🔁 Custom Iterator Practice
Custom Python iterators (`Counter` and `ReverseString`) built from scratch to practice the iterator protocol (`__iter__` / `__next__`).

A CRUD-based student registration system supporting add, list, search, update, and delete operations.
